Translate text between languages with the free MyMemory service (needs internet). Compare the original and the translation side by side, then edit before you use it — machine translation can word things oddly, so always check names and numbers.

About Zomi (Tedim)

Zomi (Tedim) has no automatic translator yet — no honest app can translate into Zomi for you today. Write or paste your Zomi script in the Create Video editor (step 04 / timed lines) and add English subtitles manually. Anyone who sells you “auto Zomi translation” is faking it.

Free service — long text is translated in pieces; very heavy use can hit a daily limit.

Settings

Everything here is stored only in this browser, on this device. Nothing is sent anywhere except the requests you start yourself.

◆Gemini AI key — story analysis & recap scripts

Story analysis and AI recap scripts use Google's Gemini with your own free AI Studio key. The key is stored only in this browser on this device and is sent only to Google when you tap Analyze or Generate. Use a fresh key, and never share the key — or screenshots showing it — with anyone.

Model used: gemini-2.5-flash. Free keys have a daily limit — if analysis stops with a quota message, wait and try again tomorrow, or the basic modes still work.

◆AUTO server (optional)

The AUTO server mode in Create Video → Export sends your clip to a Recap Studio v3 server you run (PC, VPS, or free Google Colab). Paste its address here — it changes each time a free Colab session restarts.

◆Defaults

Default video shape is the aspect buttons in step 01 of Create Video — your last choice is remembered for the open project. Voice choice here applies to the dub preview in step 06.

◆Honest limits of this app

  • Transcription (Whisper tiny) and rendering run on your phone — short clips are fast; long videos are slow.
  • The AI dub voice can be heard live but a browser cannot record it into the exported video. For an AI voice inside the file, use AUTO server mode.
  • Story analysis & AI scripts need your free Gemini key and internet.
  • Translation (MyMemory) is a free service — check every line before posting.
  • Zomi (Tedim) has no automatic translator or voice yet — write Zomi text yourself in the editor; do not trust any tool that claims otherwise.
  • Projects, scripts and settings live only in this browser. Clearing browser data deletes them.
